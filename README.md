# 🐶 Min Påklædningsdukke

Et lille interaktivt påklædningsspil bygget ud fra en håndtegnet illustration.
Træk tøjet hen på hunden — eller klik på det. Klik igen for at tage det af.

**Spil den her:** åbn `index.html` i en browser, eller besøg den udgivne URL (GitHub Pages).

## Funktioner
- Træk-og-slip **og** klik-for-til/fra (virker med mus og touch)
- Tastatur: piletaster flytter det valgte, `Delete` fjerner
- 🎲 **Overrask mig** — tilfældig outfit
- 📸 **Gem billede** — hent et PNG af den påklædte dukke

## Om filerne
- `index.html` — hele spillet i én selvstændig fil (alle billeder er indlejret)
- `illustrations_01.png` — den originale tegning
- `pieces/` — de enkelte udklip (dukke, tøj, hårelastikker, sko)

Lavet af far og datter. 🎨
